# Обмен книгами

Сервис для каталога книг, бронирований, сроков возврата и мест выдачи.

Экраны: каталог, книга, бронирования, места выдачи, статистика.

Сценарии: поиск книги, просмотр, бронирование, контроль срока возврата.

## Стек

- frontend: React, TypeScript, Material UI;
- backend: FastAPI, SQLAlchemy;
- база данных: PostgreSQL;
- запуск: Docker Compose.

## Запуск

```
cp .env.example .env
```

Задать пароль в `.env`, затем:

```
docker compose up --build
```

- frontend: `http://127.0.0.1:5173`;
- API: `http://127.0.0.1:8001`;
- Swagger: `http://127.0.0.1:8001/docs`.

Остановка:

```
docker compose down
```

## Данные

- `Location` - место выдачи;
- `Book` - книга, связанная с местом выдачи;
- `Reservation` - бронирование книги со сроком возврата.

## API

- `/locations` - места выдачи;
- `/books` - книги;
- `/reservations` - бронирования;
- `/statistics` - статистика;
- `/auth` - регистрация, вход, обновление токена и выход;
- `/health` - проверка backend.

Для мест выдачи, книг и бронирований доступны создание, чтение, изменение и удаление. Срок бронирования - 21 день.

Каталог доступен без входа. Изменение данных и бронирования требуют авторизации.

Access token действует 15 минут, refresh token - 7 дней.

## Структура frontend

- `app` - маршруты и тема;
- `pages` - страницы;
- `features` - действия пользователя;
- `entities` - данные и компоненты сущностей;
- `shared` - общие компоненты.

Формы имеют клиентскую валидацию. Для данных есть состояния загрузки, ошибки и пустого результата.
