# BookLoop

MVP сервиса обмена бумажными книгами. Пользователь находит книгу в каталоге, выбирает место выдачи, бронирует экземпляр и следит за сроком возврата. Раздел статистики показывает активность сообщества.

## Лабораторная №1: интерфейс

Основные сценарии:

- поиск и фильтрация книг в каталоге;
- просмотр книги и выбор точки выдачи;
- просмотр текущих и завершённых бронирований;
- поиск удобного места выдачи;
- просмотр простой статистики обмена.

Экраны: каталог, карточка книги, бронирования, места выдачи и статистика. На этом этапе используются демонстрационные данные.

## Стек

- React 18, TypeScript, Vite;
- Material UI;
- React Router.

Backend на FastAPI, PostgreSQL и SQLAlchemy будет добавлен в лабораторной №2.

## Запуск frontend

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется по адресу `http://127.0.0.1:5173`.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

Секреты хранятся только в локальных `.env`-файлах и не попадают в Git.
